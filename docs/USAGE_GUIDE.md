# Mineradio 扩展版使用教程

这份教程面向普通用户，默认你只想下载安装包并开始听歌，不需要会 Git 或命令行。

## 1. 下载和安装

1. 打开最新版下载页：[Mineradio-Extended Releases](https://github.com/daaimengermengzhu/Mineradio-Extended/releases/latest)。
2. 在 `Assets` 区域下载 `Mineradio-1.1.4-Setup.exe`。
3. 双击安装包，按提示安装。
4. 安装完成后，从桌面快捷方式或开始菜单打开 Mineradio。

不要下载 `Source code`、`.blockmap`、`latest.yml`。这些不是普通用户直接运行的安装包。

## 2. 登录音乐账号

打开播放器后，可以在账号/登录入口选择平台。

| 平台 | 标签 | 说明 |
| --- | --- | --- |
| 网易云音乐 | `NE` | 原项目已有接入，可用于搜索、歌单和播放。 |
| QQ 音乐 | `QQ` | 原项目已有接入；如果扫码状态异常，可以稍后重试或改用其它音源。 |
| 酷狗概念版 | `KG` | 扩展版新增，支持扫码登录、搜索、播放、歌单、红心、收藏、歌词和评论。 |
| 普通酷狗音乐 | `KGM` | 扩展版新增，和酷狗概念版分开登录、分开保存状态。 |
| 汽水音乐 | `QS` | 支持扫码登录、搜索、歌单读取和分享导入；网页通道支持免费歌曲完整播放，部分歌曲仅试听。 |

建议需要哪个平台就登录哪个平台。多个平台同时登录后，可以在“我的歌单”里切换不同平台的歌单。

## 3. 搜索和播放

顶部搜索框支持按平台筛选：

- `All`：混合搜索多个平台。
- `NE`：只搜网易云。
- `QQ`：只搜 QQ 音乐。
- `KG`：只搜酷狗概念版。
- `KGM`：只搜普通酷狗音乐。
- `QS`：搜索汽水歌曲或歌手，也可粘贴分享链接导入。

酷狗系歌曲会按实际播放来源显示音质。酷狗概念版和普通酷狗音乐目前使用四档文案：

- `Hi-Res音质`
- `无损音质`
- `高品音质`
- `标准音质`

如果请求高音质但平台实际只返回较低码率，播放器会以实际返回结果为准。

## 4. 管理第三方音源脚本

第三方音源是可选的播放地址兼容功能，不是新的登录平台。

1. 使用桌面应用，点击右上角的插头图标。
2. 点击“导入 `.js` 脚本”，选择来源可信且符合落雪自定义音源 API 2.0.0 的脚本。
3. 导入时播放器会先在隔离环境中验证脚本；验证成功后仍需手动点击“启用”。
4. 同一时间只能启用一个脚本。需要恢复纯官方链路时，点击“停用当前音源”。
5. 可以在同一弹窗中替换或删除本机脚本副本。
6. 在“播放来源优先级”中，可分别设置网易云、QQ、酷狗概念版和普通酷狗的播放顺序。设置会保存在本机。

“官方优先”保持原有逻辑，只在官方请求出现网络、地址失效或格式兼容等技术问题时尝试脚本；“落雪优先”会先用官方结果确认当前账号具备正常播放权限，再优先尝试脚本，脚本失败则使用官方地址；“仅官方”不会调用脚本。登录、会员、购买、试听和版权限制在任何模式下都不会触发第三方解析。

当前可映射网易云、QQ、酷狗概念版和普通酷狗歌曲。汽水音乐没有落雪标准平台键，不能通过此功能解析。

注意：脚本可能把歌曲名称、歌手和歌曲 ID 等必要信息发送到外部服务。本仓库不提供脚本下载和推荐，请不要导入来源不明的文件。

## 5. 使用汽水音乐（预览）

在桌面客户端点击“登录 → 汽水音乐”，使用**抖音 App** 扫码并确认。登录后打开“我的歌单”，尝试读取汽水个人歌单与喜欢列表；切换搜索框的 `QS` 可搜歌。播放器会尝试汽水原生音频，并在需要时使用官方网页通道：已实测免费歌曲完整播放，会员歌曲通常仅提供约 30 秒试听，具体以平台返回为准。

二维码生成、轮询、取消、真实账号扫码登录、公开搜索和原生音频播放已实测。试听时会显示通道限制提示；平台提供片段起点时，歌词会按起点对齐。这不表示你的登录或会员已失效。**会员完整播放、汽水收藏写入和评论发布暂未接通**。个人歌单与喜欢列表的内容完整性仍待更多账号验证，暂不保证与手机 App 完全一致。

为排除同名歌曲换源，发布前还在仅加载汽水接口、禁用其他平台的环境下播放了 AnliD 的《The Unfinished Song（慵懒版）》。[作者发布时标注汽水独家](https://www.douyin.com/video/7593561299742229689)，本次确认音频来自汽水原生通道，返回约 30 秒试听；另有免费歌曲完整播放通过实测。这不代表该曲当前在其他平台一定没有上架，也不代表已接通会员整曲。

原有分享导入仍可使用：

1. 在汽水音乐里复制分享歌单链接。
2. 回到 Mineradio，把链接粘贴到搜索框。
3. 播放器会尝试解析分享页并生成本地“汽水音乐歌单”。
4. 导入成功后，可以在“我的歌单”里直接打开这个本地歌单。

如果汽水原生播放暂时失败，播放器仍可按现有换源策略尝试其它平台；切换来源时会显示提示。

## 6. 管理歌单和排序

打开“我的歌单”后，可以进入歌单详情页。

当前支持的常用排序：

- 平台顺序：保留平台返回的顺序，不再自动倒置。
- 反向顺序：手动反转当前平台的顺序。
- 歌手名：适合按歌手整理。
- 本地播放次数：使用本播放器里的本地播放记录，不等于音乐平台官方全量播放次数。

默认使用“平台顺序”。歌单详情、3D 歌单架和整单播放使用一致的排序规则。

“我喜欢”缺失封面时会显示默认爱心图，普通歌单也有默认封面；加载歌曲后，有可用歌曲封面时会补全显示。这个变化只影响 Mineradio 的展示，不会修改你在音乐平台上的歌单封面。

酷狗平台可能返回部分平台播放次数，但它不是完整终身听歌数据库。没有返回的数据会显示为暂无或 0，不应理解为你从未听过。

## 7. 收藏、红心和新建歌单

酷狗概念版和普通酷狗音乐都已接入写入操作：

- 红心喜欢
- 新建歌单
- 收藏当前歌曲到歌单

这些操作会修改你的真实音乐平台账号。使用前请确认当前登录的是你自己的账号。

## 8. 个性化 Home 海报

首页左侧有“我的音乐海报”：

- `换图片`：选择一张本地图片作为海报背景。
- `用当前封面`：把正在播放的歌曲封面作为海报图。
- `改文案`：在页面内编辑一句自己的文字。
- `重置`：恢复默认海报。

图片和文案保存在本机浏览器本地存储里，不会上传到仓库或外部服务。

## 9. 内置视觉、DIY 和形态工坊

视觉控制台里有“我的作品”和“形态工坊”。

### 内置预设

打开视觉控制台的“预设”页即可选择内置视觉。v1.1.4 从原版移植四款预设：**月蚀圣环、雨幕霓虹、折光蝶群、深海绽放**，现在共 11 款。无需导入文件，点击即可切换；也可以继续用下面的工坊创建自己的形态。

### 我的作品

“我的作品”用于保存一整套视觉配置，例如背景、颜色、粒子、歌词、镜头和部分交互参数。

支持：

- 新建作品
- 保存当前配置
- 复制作品
- 导入 `.mineradio-visual.json`
- 导出 `.mineradio-visual.json`

### 形态工坊

“形态工坊”用于创建自己的 3D 粒子形态。

基础流程：

1. 打开视觉控制台。
2. 进入“预设”页。
3. 点击“创建形态”。
4. 选择点、线、环、曲线环、面、螺旋、波、隧道、球面、星尘、卡片等基础粒子。
5. 拖动舞台上的手柄调整位置和角度。
6. 用右侧滑条调整数量、大小、前后厚度、透明度和随音乐动。
7. 默认是静态编辑；需要看动态效果时再打开“律动预览”。
8. 保存为“我的形态”后，可以像内置预设一样应用到播放器。

支持导入/导出 `.mineradio-shape.json`。公开版不会内置二创作者个人实验形态，用户形态需要自己创建、保存或导入。

## 10. 帧率与后台占用

打开视觉控制台，展开“高级参数”，找到“前台帧率”：

- **30 · 省电**：降低绘制频率，适合希望减少占用时使用。
- **60 · 均衡**：默认设置。
- **跟随屏幕**：跟随屏幕刷新频率；高刷新率屏幕上的占用可能更高。

窗口隐藏且没有后台视觉需求时，播放器会停止不必要的逐帧绘制，恢复显示后继续运行。桌面歌词仍独立更新；开启“直播后台保持”等功能时会按需保留后台视觉。实际占用取决于预设、画质、屏幕与设备。

汽水音频缓存最多保留一首，单曲上限 64 MB，并在 90 秒后释放，避免持续积累。

## 11. 均衡器

点击底部的 `EQ` 可以打开十段均衡器。均衡器默认关闭；开启后会作用于所有播放来源，也会作用于本地歌曲。

- 开启后可立即试听原声、低音增强、人声清晰、流行、摇滚、古典六种预设。
- 拖动任意频段会进入“自定义”，播放器会保存一条自定义曲线。
- 关闭均衡器不会清除曲线，再次打开时会恢复原有设置。
- 点击“重置为原声”会把十个频段恢复到 `0 dB`，不会意外改变均衡器的开启或关闭状态。

均衡器只调整 Mineradio 在本机播放出来的声音，不会修改歌曲文件；它与网易云、QQ 音乐、酷狗的平台音质和官方音效相互独立。提升频段时，播放器会自动预留响度余量并进行峰值保护，降低过载风险；增强较多时整体响度可能略有下降。

## 12. 常见问题

### 下载被浏览器拦截怎么办？

确认文件来自本仓库 Release 后，可以在浏览器下载列表里选择 `保留` 或 `仍要保留`。如果系统或杀毒软件明确报高危，不要强行运行，建议重新下载并反馈截图。

### 为什么汽水歌单能导入，但有些歌实际播放走了别的平台？

当汽水账号未登录、原生地址不可用或音频格式无法播放时，现有换源策略可能匹配其它平台的同名歌曲。播放时请留意来源提示；会员和版权限制仍由各平台决定。

### 登录了汽水会员，为什么还是只能试听？

目前接通的官方网页通道可能只返回试听片段，汽水会员完整播放尚未接通。看到“汽水网页通道仅提供约 30 秒试听”等提示时，无需因此反复扫码；其他平台的会员也不会改变汽水通道返回的时长。

### 喜欢歌单为什么还是默认爱心封面？

平台未返回歌单封面、且歌曲还没有可用封面时，会显示本地默认爱心图。加载到可用歌曲封面后会补全；空歌单仍使用默认图。

### 为什么显示的播放次数和手机 App 不一样？

本地播放次数只统计你在 Mineradio 里播放过的次数。部分平台播放次数来自平台接口能返回的范围，不保证覆盖账号完整历史。

### 酷狗音效在哪里？

当前没有接入酷狗官方音效。公开版不会用本地 WebAudio 模拟效果冒充官方音效。

### 导入第三方音源后为什么仍然提示需要会员？

第三方音源不会接管会员、购买、登录或版权限制，即使选择“落雪优先”也一样。出现这类提示时，需要使用对应平台具备权限的账号或选择其它合法可播版本。

## 13. 版权和平台规则

本项目不是网易云、QQ 音乐、酷狗音乐或汽水音乐的官方客户端。请遵守对应平台的用户协议、版权规则和会员权益规则。

本项目不会提供绕过付费、绕过会员、破解音质或重新分发音乐内容的能力。
